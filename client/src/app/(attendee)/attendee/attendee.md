# Attendee Section Documentation (`client/src/app/(attendee)/attendee`)

## A. Directory Overview
The `client/src/app/(attendee)/attendee` directory houses the sub-routes dedicated to authenticated attendees. It groups the dashboard overview and registrations management screens under the `/attendee/*` URL path.

## B. Directory Structure
```text
client/src/app/(attendee)/attendee/
├── attendee.md          # This documentation file
├── dashboard/           # Attendee overview dashboard route
│   ├── dashboard.md
│   └── page.tsx
└── registrations/       # Attendee tickets and cancellation requests route
    ├── registrations.md
    └── page.tsx
```

## C. File-by-File Documentation
There are no direct source files in `client/src/app/(attendee)/attendee/`; logic is divided into the two route subdirectories documented below.

## D. Child Directory Documentation
